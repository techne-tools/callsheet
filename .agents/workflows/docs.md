# Documentation Workflow

1. Scan the project for undocumented or poorly documented public APIs and modules.
2. Generate or update inline documentation (JSDoc, docstrings).
3. Update the README.md if structural changes are detected.
4. Ensure all exported functions and classes have proper type annotations and descriptions.
5. Keep docs current: if you change architecture, conventions, or a risk area meaningfully, update the relevant file in the same change.
